# LeanVPN — стартовый Android-проект

## Важно
Это **стартовый интерфейс**, а не готовый VPN-сервис. Он показывает экран и запрашивает разрешение Android на VPN. Реальный защищённый туннель, серверы и конфигурация WireGuard пока не подключены. Не используй эту сборку для защиты трафика и не обещай пользователям анонимность.

## Как получить APK только с телефона
Самый простой вариант — собрать проект через GitHub Actions в браузере телефона.

1. Создай аккаунт GitHub, если его ещё нет.
2. На GitHub нажми **+ → New repository**, назови его `LeanVPN` и создай репозиторий.
3. Распакуй архив на телефоне.
4. Загрузи все файлы и папки из `LeanVPN-Android` в репозиторий, сохранив структуру. Важно загрузить скрытую папку `.github/workflows` с файлом `build-apk.yml`. Если мобильный сайт не позволяет загрузить папку целиком, удобнее открыть GitHub в браузере в режиме «Версия для ПК» или загрузить файлы через GitHub Mobile/веб-интерфейс по частям.
5. Открой вкладку **Actions** в репозитории. Если GitHub попросит включить Actions, разреши.
6. При первом коммите workflow обычно запускается автоматически. Иначе открой **Build LeanVPN APK** → **Run workflow**.
7. Дождись зелёной галочки. Открой завершённый запуск, найди раздел **Artifacts** и скачай `LeanVPN-debug-apk`.
8. Распакуй скачанный ZIP и найди `app-debug.apk`. Открой APK и следуй подсказкам Android для установки. Устанавливай только APK, собранный из собственного репозитория.

## Что дальше для настоящего VPN
Нужны: VPN-протокол (например, WireGuard), сервер, безопасная выдача конфигураций и полноценная реализация туннеля. Не вставляй в публичный репозиторий приватные ключи, пароли или конфиги с секретами.
